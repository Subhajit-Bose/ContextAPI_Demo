# React Context API Demo

A simple React project demonstrating the Context API for sharing state between components without prop drilling.

## Features
- Global state management using `createContext`.
- Share user data using Context Provider.
- Update user data through a login form.
- Access shared data using `useContext`.
- Minimal teal-themed UI.

## Tech Stack
- React
- JavaScript
- CSS

## Run Locally

```bash
npm install
npm run dev
```

### Note: This is a learning demo, not a production-ready authentication system.
